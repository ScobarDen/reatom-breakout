# Модуль breakout без View

Модуль `breakout` держит только Model и ViewModel, а View каждой сборки живёт на своей странице: `pages/jsx/`, `pages/dom/`, `pages/react/` и так далее ([ADR-0004](0004-view-builds-instead-of-terminal-host.md)). Обычно View лежит внутри модуля и экспортируется из его `index.ts`, но у модуля один `index.ts`. Если бы все View лежали там, DOM-сборка, импортировав модуль, потащила бы React и `@reatom/jsx`, по крайней мере в dev, где tree-shaking не работает.

Изначально решение принималось из-за терминального хоста: его View тянула нативный `@opentui/core`, который в браузере не грузится. Терминала больше нет, а причина держать View вне модуля осталась, только теперь это чужой фреймворк, а не нативный пакет.

## Рассмотренные варианты

- View всех сборок внутри модуля, общий `index.ts`: каждая сборка тащит фреймворки остальных.
- Подмодули `breakout/jsx/`, `breakout/react/` со своими `index.ts`: подмодуль виден снаружи в обход родителя, а через родителя фреймворк тянется всё равно.
