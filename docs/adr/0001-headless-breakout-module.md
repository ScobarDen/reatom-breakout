# Модуль breakout без View

Модуль `breakout` держит только Model и ViewModel, а View каждого хоста живёт на своей странице: `pages/web/` и `pages/terminal/`. Обычно View лежит внутри модуля и экспортируется из его `index.ts`, но у модуля один `index.ts`. Импортировав его, web-бандл потащил бы терминальную View вместе с `@opentui/core`, а это нативное ядро на Zig, которое в браузере не загружается.

## Рассмотренные варианты

- Вьюхи хостов внутри модуля, общий `index.ts`: web ломается на нативном пакете, а tree-shaking в dev не спасает.
- Host-подмодули `breakout/web/` и `breakout/terminal/` со своими `index.ts`: тогда подмодуль виден снаружи в обход родителя, а через родителя пакет тянется всё равно.
