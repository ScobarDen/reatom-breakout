# Экран живёт в URL модуля screens, без порта

Замещает [ADR-0003](0003-screen-port.md). Какой **Screen** открыт, модуль `screens` хранит сам: search-only `reatomRoute` на параметре `?screen=`. Порт `{ screen, open }` был нужен только терминалу, у которого нет URL. Когда все сборки живут в браузере, у порта осталась одна реализация. Пауза при уходе с Match по-прежнему висит на переходе `screen` из `match` в другое значение, а не на экшене переключения. Поэтому паузу ставят и клик по вкладке, и «назад» в браузере, и открытие `?screen=results` по ссылке.

## Последствия

- Сборки без экранов (canvas, звук) не подключают модуль `screens`, и `?screen=` в их адресе ничего не делает.
- У pathless-роута `go` пересобирает query только из своих параметров, поэтому следующий search-параметр (фильтр Results) должен жить в том же роуте или пережить переход сам.
